Clean Print – Privacy Policy

Last updated: 2026-10-29

Clean Print is a browser extension that lets you edit a copy of the web page you are viewing and print it or save it as a PDF. It is designed to work entirely inside your browser.

What the extension accesses

  • Page content you choose to print. Only when you click the Clean Print icon or press its keyboard shortcut, the extension reads the content and styles of the page in the active tab (Chrome's activeTab permission) and copies it into the extension's own editor tab.
  • Your layout preferences. Font size, margins, paper size and the checkbox options in the editor are saved locally in your browser (storage permission) so they are remembered next time.

What the extension does not do

  • It does not send any data to any server. There is no backend, no analytics and no account.
  • It does not read pages in the background or on tabs you have not clicked the icon on.
  • It does not store page content persistently. The page snapshot lives only in the browser's session memory for the editor tab and is discarded when the browser closes.
  • It does not use cookies, tracking, advertising identifiers or remote code.

Data sharing

No data is shared with or sold to third parties. Clean Print does not transfer user data to anyone, for any purpose.

Third-party code

The extension bundles Mozilla Readability (Apache License 2.0) to extract article content locally. It runs inside the extension and makes no network requests.

Clean Print – Gizlilik Politikası

Son güncelleme: 29.10.2026

Clean Print, görüntülediğin web sayfasının bir kopyasını düzenleyip yazdırmanı veya PDF olarak kaydetmeni sağlayan bir tarayıcı eklentisidir. Tamamen tarayıcının içinde çalışacak şekilde tasarlanmıştır.

Eklentinin eriştikleri

  • Yazdırmak istediğin sayfanın içeriği. Yalnızca ikona tıkladığında ya da kısayola bastığında, etkin sekmedeki sayfanın içeriğini ve stillerini okur (activeTab izni) ve kendi editör sekmesine kopyalar.
  • Düzen tercihlerin. Yazı boyutu, kenar boşluğu, kâğıt boyutu ve onay kutusu seçenekleri tarayıcında yerel olarak saklanır (storage izni).

Eklentinin yapmadıkları

  • Hiçbir sunucuya veri göndermez. Sunucu, analitik ya da hesap yoktur.
  • Arka planda ya da ikona tıklamadığın sekmelerde sayfa okumaz.
  • Sayfa içeriğini kalıcı olarak saklamaz; anlık görüntü yalnızca editör sekmesi için oturum belleğinde tutulur ve tarayıcı kapanınca silinir.
  • Çerez, izleme, reklam tanımlayıcısı veya uzak kod kullanmaz.

Veri paylaşımı

Hiçbir veri üçüncü taraflarla paylaşılmaz ya da satılmaz.
